This package simplifies accessing public transport backends
like OpenTripPlanner and MOTIS, and using realtime data like GTFS-RT.
Inspired by [KPublicTransport](https://invent.kde.org/libraries/kpublictransport)
(although no code was ported).

## Features

When having internet access and an endpoint for a service, you can:

* Find stops and stations by name or a bounding box.
* Get a list of upcoming arrivals or departures for a given stop.
* Plan a journey and get detailed information on its parts.
* Obtain a specific trip information including its geometry when available.
* Receive real-time updates to schedules and vehicle locations.
